# Geography prompt review gates

Use these gates with the general method. Exact places, precincts, landmarks, table values, URLs, and outcomes remain in ignored local notes.

## Geographic scope

- Freeze the historical census year and the exact geography type: state, county, city, precinct, ward, tract, or the portion of one unit inside another.
- Treat a full precinct row, a city total, and an `in precinct` subdivision as different scopes even when they share a number or place name.
- Carry a place-name key from independent historical evidence into the terminal table; do not disclose the row number when the name itself can select it.
- Record the values for every same-page parent, child, and neighboring geography before promotion.

## Terminal table

- Verify multi-level census headers and row alignment from the rendered page image.
- State the requested header naturally, but do not supply the table number, page, precinct number, and adjacent value together.
- Ask for a directly printed census cell. Do not derive a residual, percentage, rate, or boundary conversion.
- Reject candidates whose answer is exposed by a modern profile, search snippet, OCR preview, or one obvious city-total row.

## Source graph and wording

- Use independent landmark, founder, planning, or historic-register evidence only when each fact selects a real place or row label.
- Require at least one scope decision after the terminal document is found and one column decision inside the selected row.
- Repeat the geography type instead of using `it`, `there`, or `its` when city and precinct are both in scope.
- Use human-readable HTML/PDF sources with exact pages; do not submit API, JSON, YAML, or large flat-file lookup paths.
