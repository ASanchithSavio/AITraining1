# Domain strategy map

Use this map to choose promising document ecosystems. It is a research starting point, not an approval list: every individual page must still pass accessibility, stability, textual-verification, and source-independence checks.

| Domain | High-yield source families | Good terminal facts | Frequent traps |
|---|---|---|---|
| Art | Museum catalogs, provenance studies, exhibition archives, artist papers, auction catalogs | Checklist entry, prior owner, installation detail, lot annotation | Image-only labels, subjective attribution, copied catalog wording |
| Business | Regulatory filings, procurement attachments, historical annual reports, court exhibits, corporate directories | Exhibit clause, bid-table entry, officer/date in a filing | Current company pages, redundant filings, finance arithmetic |
| Celebrities / Public Figures | Public archives, correspondence, schedules, yearbooks, oral histories, court records | Early-career credit, dated role, obscure institutional link | Gossip sources, disputed biography, famous-name shortcut |
| Education | Institutional repositories, accreditation reports, catalogs, board packets, yearbooks, theses | Course code, program name, table entry, historical officeholder | Live faculty pages, changing curricula, one-document lookup |
| Finance | Regulatory filings, bond statements, historic banking reports, country reports, fund documents | Defined table cell, covenant phrase, dated disclosure | Prices/tickers, arithmetic, mixed reporting periods |
| Geography | Gazetteers, soil surveys, environmental reports, census yearbooks, land-use plans | Historical place name, bounded table row, named geographic unit | Map-only evidence, changing boundaries, non-English or dynamic pages |
| Health & Medicine | Regulatory reviews, labels, surveillance reports, archival public-health publications | Approval detail, report table entry, historical recommendation | Clinical advice, outdated conclusions, inaccessible journals |
| History | Archives, directories, proceedings, newspapers, diaries, legislative reports | Dated notice, roster entry, address, archival identifier | OCR errors, ambiguous people, unbounded newspaper searches |
| Legal | Court filings, decisions, regulations, hearings, committee reports, administrative records | Docket exhibit fact, defined term, section-specific finding | Current-law drift, legal-advice framing, inaccessible dockets |
| Music | Scores, catalogs, programs, trade journals, label bulletins, discographies | Edition detail, instrumentation, program listing, catalog number | Lyrics, image-only notation, release-version ambiguity |
| Politics | Hearings, diaries, correspondence, schedules, campaign filings, local agenda packets | Dated memo detail, committee record, completed-event role | Current officeholders, partisan claims, recurring meetings |
| Science & Technology | Technical reports, standards, patents, field surveys, taxonomic monographs | Test condition, figure caption text, patent element, report table | Derived calculations, version drift, unreadable diagrams |
| Shopping | Manuals, historical catalogs, recalls, service bulletins, procurement specifications | Model-specific part, catalog descriptor, recall code | Live prices/stock, variant ambiguity, retailer pages |
| Sports | Official record books, media guides, game notes, event reports, historical newspapers | Bounded roster/rank, obscure box entry, historical record | Live leaderboards, copied exemplar chains, prohibited source networks |
| Travel | Visitor brochures, management plans, heritage dossiers, historical guidebooks, transport guides, infrastructure reports | Lodging name, route/table entry, facility, trail or visitor-service detail | Live fees/schedules, optional-cost baskets, map-only facts, famous destinations |
| TV Shows & Movies | Trade papers, pressbooks, scripts, production notes, broadcast archives | Release detail, credited role, program listing, production note | Fan wikis, one-page cast lookup, title/version ambiguity |
| Video Games | Manuals, magazines, developer records, press kits, hardware patents, strategy guides | Manual wording, level/item detail, issue-specific review fact | Wiki shortcuts, patch/version drift, inaccessible scans |

## Cross-domain source families

Useful general reservoirs include national libraries, public archives, government publication systems, university repositories, historic newspaper collections, and digitized books or catalogs. These are discovery layers, not automatic verification sources. A final citation still needs a direct, stable page with readable text.

## Selecting a domain strategy

1. Pick a document family native to the seeded domain.
2. Mine several candidate terminal facts before drafting anything.
3. Prefer facts that have nearby distractors and a clear bounded scope.
4. Find independent source ecosystems that can lead to the terminal record without naming it.
5. Reject any chain that needs unrelated biographical, political, or historical glue merely to add hops.
6. Check current benchmark bans before relying on a famous example, framework, or source network.
