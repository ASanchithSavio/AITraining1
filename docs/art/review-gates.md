# Art prompt review gates

Use these gates with the general method. Exact artworks, answers, URLs, catalogue identifiers, and test outcomes remain in ignored local notes.

## Domain and answer

- Keep the research native to art history, museum cataloguing, provenance, conservation, exhibition history, or an artist's documented practice.
- Ask for one directly printed name, material, pigment, owner, catalogue label, installation detail, or short annotation.
- Reject aesthetic judgments, disputed attributions, unsupported iconographic readings, and answers that require visual guessing.
- Fix the date, catalogue edition, conservation survey, or exhibition version whenever later scholarship could change the record.

## Source graph

- Use at least three independent publication ecosystems when the benchmark requires independent hosts.
- A strong chain can use one source to identify the artist, a collection record to select the exact object, and a technical catalogue or conservation report to supply the terminal fact.
- Each source must eliminate a real alternative. Biographical clues, provenance names, and catalogue identifiers should not merely reconfirm an artwork already named elsewhere.
- Reject a chain if a general collection page or search snippet independently exposes both the target object and the final answer.

## Object identity and provenance

- Preserve exact title variants, capitalization, dates, medium, dimensions, object numbers, and owner sequence.
- Treat near-identical titles as separate objects until identifiers and provenance prove otherwise.
- Do not silently normalize translated titles or confuse a study, drawing, panel, finished painting, print, or later copy.
- When provenance selects the object, verify the full relevant sequence and any repeated dealer or gallery appearance.

## Technical tables and catalogues

- Visually inspect every decisive table page, including continuations where row labels or column headings are not repeated.
- Record the target row's ordinal position before following that row across a page break.
- Check the rows immediately above and below the target, especially when their titles differ by only one word.
- Preserve qualifiers, traces, mixtures, footnote markers, and column scope; do not turn a table category into a broader material claim.
- Use extraction or code only to confirm alignment and uniqueness. The printed catalogue remains the terminal evidence.

## Shortcut, language, and empirical gates

- Search exact title fragments, object identifiers, provenance combinations, catalogue titles, and the proposed answer.
- Check whether snippets expose separate row-label and value lists that a solver could incorrectly zip together.
- Run a grammatical-attachment audit after all edits. Repeat `artist`, `target artwork`, `provenance`, and `survey` when a pronoun could point to more than one entity.
- A plausible wrong answer should belong to a neighbouring object, edition, owner, or table row, not to an unrelated famous work.
- Passing these gates makes a candidate ready for a user-run target-model test; it does not prove that the candidate is difficult.
